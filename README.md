# STREAM · 本地视频管理器

Netflix 风格的本地视频管理器：扫描本地（或 NAS/UNC 路径）视频目录，自动生成封面墙，浏览器内直接流式播放。FastAPI 后端 + 原生 JavaScript 前端，无任何前端框架依赖。

## 下载发行版

无需安装 Python，直接从 [Releases](https://github.com/bairain/stream/releases) 下载：

| 包 | 说明 |
|---|---|
| `STREAM_v*.zip` | 客户端版：独立原生窗口（Win11 深色标题栏），关窗即退出 |
| `STREAM_Web_v*.zip` | 浏览器版：启动后自动打开默认浏览器，也可从局域网其他设备访问 |

**使用方法**：解压到任意目录 → 运行 `STREAM.exe`（或 `STREAM_Web.exe`）→ 首次启动点击右上角 ⚙ 设置媒体根目录。

- 程序为绿色免安装，所有数据（配置、缩略图缓存、观看历史）都生成在 exe 旁边，整体移动或删除目录即可携带/卸载
- 首次运行可能弹出 Windows SmartScreen 提示（程序未签名），点击「仍要运行」即可
- 升级版本时保留 `config.json`、`.data/`、`.thumbs/` 三个文件/目录，其余替换为新版即可

## 功能特性

- **媒体库扫描** — 递归扫描媒体根目录，按层级组织成类别与影片；支持局域网共享路径（UNC），自动处理中文路径
- **自动封面** — OpenCV 抽帧生成缩略图，本地缓存（`.thumbs/`），支持在设置中为任意影片指定自定义封面
- **双播放模式** — 网页播放器（HTTP Range 流式播放，支持断点续播、上下集切换）或调用系统播放器（VLC / mpv / 自定义）
- **个人化** — 自定义栏目（收藏）、观看历史、即时搜索
- **外观设置** — 卡片大小（小/中/大）、卡片比例（16:9 / 21:9 / 4:3 / 3:4 / 9:16）、卡片标题开关
- **局域网模式** — 服务广播到局域网，手机/平板等其他设备可直接访问；远程设备不可更改媒体目录

## 快速开始（源码运行）

要求：Python 3.10+，Windows 下体验最佳。普通使用建议直接[下载发行版](#下载发行版)。

```bash
pip install -r requirements.txt
python app.py
```

启动后自动打开 `http://127.0.0.1:8501`。首次运行请点击右上角 ⚙ 设置媒体根目录，或直接编辑 `config.json`：

```json
{
  "media_root": "D:\\Movies",
  "port": 8501
}
```

## 使用说明

### 1. 准备媒体库

按 `媒体根目录 → 类别 → 影片 → 分集` 的层级组织视频文件：

```
D:\Movies\                  ← 媒体根目录（config.json 的 media_root）
├── 电影\                   ← 一级子目录 = 顶栏类别
│   ├── 盗梦空间.mp4        ← 类别下直接放视频 = 单部电影
│   └── 星际穿越.mp4
└── 番剧\
    ├── 进击的巨人\         ← 类别下建目录 = 一部剧集
    │   ├── 第1话 起点.mp4  ← 目录下的视频 = 分集
    │   └── 第2话 转折.mp4
    └── 某科学超电磁炮\
        ├── 第一季\         ← 剧集目录下再建目录 = 季
        │   ├── EP01.mp4
        │   └── EP02.mp4
        └── 第二季\
            └── EP01.mp4
```

支持的视频格式：`.mp4` `.mkv` `.avi` `.mov` `.wmv` `.flv` `.webm` `.m4v` `.mpg` `.mpeg` `.ts` `.m2ts` `.rmvb` `.rm` `.3gp` `.vob` `.ogv`（网页内直接播放依赖浏览器解码能力，其余格式建议使用系统播放器模式）。

### 2. 日常使用

- **浏览**：顶栏切换类别，首页封面墙横向滚动；点击卡片进入详情页
- **播放**：详情页点击分集或"播放"按钮；网页播放器内可切换上/下集，断点位置自动记忆
- **搜索**：右上角搜索框即时过滤全部影片
- **收藏**：详情页可把影片加入自定义栏目，顶栏生成专属入口
- **历史**：观看过的内容自动记录，可从"我的"继续观看
- **自定义封面**：设置中可为任意影片指定一张本地图片作为封面
- **外观**：设置中调整卡片大小 / 比例 / 是否显示标题，全站实时生效
- **多设备访问**：开启局域网模式后，同一网络下的手机、平板直接访问 `http://<电脑IP>:8501`

## 配置项

| 键 | 默认值 | 说明 |
|---|---|---|
| `media_root` | `./media` | 媒体根目录，支持 UNC 路径（如 `\\\\NAS\\video`） |
| `port` | `8501` | 服务端口 |
| `player_mode` | `web` | `web` 网页播放 / `system` 系统播放器 |
| `external_player` | `default` | `default` / `vlc` / `mpv` / `custom` |
| `player_path` | `""` | `custom` 时的播放器程序路径 |
| `card_size` | `medium` | 卡片大小 `small` / `medium` / `large` |
| `card_ratio` | `16:9` | 卡片比例 |
| `card_title` | `false` | 在卡片上直接显示名称 |
| `lan_mode` | `false` | 局域网模式（广播服务，远程设备只读） |

## 项目结构

```
stream/
├── app.py               # 全部后端：API、扫描、抽帧、流式播放
├── static/
│   ├── index.html       # 单页界面
│   ├── css/style.css    # Netflix 风格样式
│   └── js/app.js        # 前端逻辑（路由、渲染、播放器、设置）
├── stream.ico           # 应用图标
└── config.json          # 运行配置（首次运行自动生成）
```

运行时自动生成的数据（不入库）：`.thumbs/` 缩略图缓存、`.data/` 栏目与观看历史、`stream.log` 日志。

## API 一览

| 路由 | 说明 |
|---|---|
| `GET /api/library` | 媒体库列表（含扫描进度 `scan_complete`） |
| `GET /api/thumb?id=` | 视频封面（OpenCV 抽帧，带缓存） |
| `GET /api/video?id=` | HTTP Range 流式播放 |
| `POST /api/rescan` | 重新扫描媒体库 |
| `GET/POST /api/config` | 读取/保存配置 |
| `/api/collections` `/api/history` `/api/cover` 等 | 栏目、历史、自定义封面 |
